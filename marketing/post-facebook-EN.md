🛠️ Free tool for VPX / PinUP cab owners — Pincab Toolbox

Like most of you, I've spent more evenings fixing my cab than playing it. So I built a small free scanner that checks your install and tells you what's broken before you hit Start:

missing ROMs · 32/64-bit DLL mismatches · Windows-blocked DLLs · missing B2S/FlexDMD deps · backglass & Popper issues · outdated tables · script diff.

100% local, read-only (it NEVER modifies anything), no account, no telemetry. It never downloads tables/ROMs/media — it's a diagnostic, not a downloader. The community sites stay THE source.

Honest heads-up: it's a v0.1 and I haven't been able to test it on a wide range of real cabs yet, so I'm after blunt feedback — try it and tell me what it misses or gets wrong. I fix fast.

👉 https://pincab-toolbox.vercel.app/
(Download, unzip, run PincabToolbox.exe from the extracted folder — keep the files together.)
(Unsigned exe for now → the usual SmartScreen "More info → Run anyway". Code signing comes later.)

If a repair version ever happens, it'll always keep a backup first + preview + undo — and the scanner stays free and read-only, forever. Happy flipping 🎱
